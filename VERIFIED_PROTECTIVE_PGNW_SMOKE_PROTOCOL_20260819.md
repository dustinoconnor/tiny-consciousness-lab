The run is eligible only if it records a red pickup followed by visible yellow
while the event is pending. A plumbing pass requires the protective gate to
activate only after red, target yellow at posterior confidence >=0.95, and stay

reported separately; zero changes means successful pickup cannot be credited to
the rule. One smoke is not a comparative efficacy result. A matched passive
counterpart is required after plumbing passes.
